# 分类标签

工程技能使用五种标准分类角色。本文件将这些角色映射到本仓库问题跟踪器使用的实际标签。

| 标准角色          | 本仓库标签          | 含义                        |
| ----------------- | ------------------- | --------------------------- |
| `needs-triage`    | `needs-triage`      | 需要维护者分类和评估        |
| `needs-info`      | `needs-info`        | 等待报告者补充信息          |
| `ready-for-agent` | `ready-for-agent`   | 信息完整，可交给 Agent 实施 |
| `ready-for-human` | `ready-for-human`   | 需要人工判断或实施          |
| `wontfix`         | `wontfix`           | 已决定不处理                |

当技能提到某个分类角色时，应使用上表中对应的本仓库标签。

`claimed` 和 `resolved` 是本地任务的执行生命周期状态，不属于上述五类分流标签：任务被唯一负责人认领后使用 `claimed`，完成验收并记录答案后使用 `resolved`。

如需采用其他标签词汇，请修改“本仓库标签”列。
