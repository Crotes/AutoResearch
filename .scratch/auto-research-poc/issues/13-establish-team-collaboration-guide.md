# 建立多人协作开发文档

Type: task
Status: resolved
Blocked by: 01
Owner: Codex

## 目标

让新成员和 Agent 能从仓库内找到一致的环境搭建、任务认领、并行开发、验证和文档同步规则。

## 范围

- 增加贡献指南和开发指南
- 规定本地任务认领、分支、提交、PR 和评审流程
- 建立代码变更与规格、领域、ADR、契约文档的同步矩阵
- 增加 Pull Request 模板
- 更新 README 与 AGENTS.md 的上下文指针

## 验收

- 新成员能独立完成环境搭建和验证
- 同一任务有明确的唯一认领入口
- 重要代码变更能判断应同步哪份文档
- PR 模板覆盖任务、风险、测试、数据安全和文档同步

## Comments

- 当前仓库尚未初始化 Git，因此文档明确区分“共享工作区顺序交接”和任务 12 完成后的“跨机器分支/PR 并行协作”。
- 未创建 `CODEOWNERS`，因为 GitHub 组织与维护者账号尚未确定；该配置归入任务 12。

## Answer

已增加贡献指南、开发指南、多人协作流程和 PR 模板，并从 README 与 AGENTS.md 建立按场景触发的入口。协作流程覆盖唯一认领、依赖检查、并行边界、交接、评审、私有数据保护和文档同步矩阵。

同时补充了本地任务的 `Owner` 规则，并澄清 `claimed/resolved` 是执行生命周期状态，与五类分流标签分开。

验证结果：19 项测试通过，Ruff 检查与格式检查通过，mypy strict 通过；所有文档入口目标均存在。
