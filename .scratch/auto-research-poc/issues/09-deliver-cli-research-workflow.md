# 交付 CLI 研究工作流

Type: task
Status: ready-for-agent
Blocked by: 02, 03, 05, 07, 08

## 目标

让研究者通过 CLI 完成项目创建、研究运行、审核、恢复、取消和导出。

## 范围

- project create
- run start、status、events、review、resume、cancel、export
- 探索模式工作流
- 三层结果的终端入口和 Markdown 导出
- 失败状态与警告展示

## 验收

- 真实研究问题可完成完整工作流
- 所有候选先生成速览，只有选中成果生成详细解读
- 分类总结只引用已选成果
- 失败来源和缺失正文不会被静默隐藏
